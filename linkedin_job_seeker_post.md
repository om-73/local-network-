### **Headline: Redefining Real-Time Monitoring: A Full-Stack Network Analysis Tool 🛡️📊**

I’m excited to share a project that pushed my technical boundaries: a **Real-Time Network Traffic Monitor**. This wasn't just about building a dashboard—it was about bridging the gap between low-level system events and high-performance web visualization.

### **🛠️ What I Used to Build It:**

To achieve sub-second latency and high-depth analytics, I leveraged a specialized tech stack:

*   **Runtime & Logic:** Node.js, Express
*   **Packet Engine:** Wireshark (`tshark`) for raw packet capture
*   **Real-Time Streaming:** Socket.IO (WebSockets)
*   **Data Visualization:** Chart.js for time-series analytics
*   **Frontend UI:** Vanilla JS, CSS3 (Glassmorphism & Neon Design System)
*   **Deployment:** Docker, Render, Vercel

### **💡 Key Learning & Skills Acquired:**

Building this from scratch allowed me to master several critical engineering skills:

✅ **Asynchronous Systems Programming:** Managed non-blocking child processes to interface with OS-level tools.
✅ **High-Velocity Data Handling:** Engineered a data pipeline to stream and render hundreds of packets per second without UI lag.
✅ **Modern UI/UX Design:** Implemented an advanced glassmorphism interface with custom-styled charts for a premium user experience.
✅ **Network Protocol Analysis:** Gained deep knowledge of TCP/IP, UDP, DNS, and HTTP internals by parsing real network packets.

This project represents my ability to handle complex system integrations and deliver high-performance full-stack solutions.
