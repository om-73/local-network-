🚀 How to Enable Real-Time Live Capture

Currently, the app is running in Demo Mode because it lacks permissions to capture real network packets.

Option 1: Run with Sudo (Recommended for Local)

Close the current backend terminal and run the server with administrative privileges:

sudo npm run dev

Option 2: Install Wireshark ChmodBPF

If you're on macOS, install the ChmodBPF component from Wireshark to allow capture without sudo:

  1. Download/Install Wireshark.
  2. During installation, ensure Install ChmodBPF is checked.
  3. Restart your terminal.
Current Interface: You are scanning on en0 (Wi-Fi). Ensure your device is connected to the network you want to monitor.
